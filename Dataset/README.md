# Dataset Information

This folder is intended to contain the dataset used for the Supply Chain Inventory & Stockout Risk Analysis project.

**Dataset details**
- Total records: 91,250
- Total columns: 15
- Format: CSV

**Main fields**
- Date
- SKU_ID
- Warehouse_ID
- Supplier_ID
- Region
- Units_Sold
- Inventory_Level
- Supplier_Lead_Time_Days
- Reorder_Point
- Order_Quantity
- Unit_Cost
- Unit_Price
- Promotion_Flag
- Stockout_Flag
- Demand_Forecast

**Note:** Check the dataset's license and sharing permissions before uploading the original CSV file.
